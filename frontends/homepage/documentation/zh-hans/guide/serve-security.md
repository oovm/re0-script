# 本地连接与安全

YYDB 是本地嵌入式数据库。它的连接服务用于同一台设备上的应用、开发工具和浏览器 WebUI，不提供用户、角色或 ACL 等公网服务能力。

## 推荐配置

- 使用默认的 loopback 地址 `127.0.0.1` 或 `::1`。
- 让 `.yydb` 文件只对运行应用的操作系统账户可读写。
- 在桌面或 Node.js 应用中优先使用产品包管理本地引擎生命周期。
- 跨主机访问时，在 YYDB 前使用具备认证、加密和访问控制的专用服务层。

## 信任边界

能够连接本地端口的进程可以访问当前打开的数据库。因此，YYDB 的信任边界由设备、操作系统账户、文件权限与本地网络配置共同构成。

`yydb serve` 默认绑定 loopback。非 loopback 监听需要显式启用，适合受控开发环境，不应作为公网数据库端点。
